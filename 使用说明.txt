TT酱 3.3.0 — 快速启动、全盘搜索与截图 OCR
=====================================

运行环境：Windows 10 1903 及以上 / Windows 11，仅 64 位。
系统自带 .NET Framework 4.8，不需要安装 .NET 8 或其他运行时，解压即用。
程序是 2.8 MB 的 TT酱.exe 加一个约 20 MB 的 ocr 目录（离线 OCR 模型，
PP-OCRv6 tiny），Everything 搜索引擎内嵌在 exe 里，全程不需要联网。
ocr 目录要和 TT酱.exe 放在一起，不要把 exe 单独拷走。

一、快速开始

1. 把整个文件夹放到任意有写入权限的本地目录（桌面、D 盘都可以，
   不要放 Program Files 这类只读目录）。
2. 双击 TT酱.exe 后，程序默认只驻留托盘，不弹出主窗口；
   双击 Ctrl 或右键托盘图标选「打开」即可显示窗口。
   开启「开机自动启动」后，开机同样只在托盘待命。
   首次启动还会：
   - 在同级目录释放 everything 文件夹（内置搜索引擎，MIT 许可）；
   - 询问是否安装索引服务（弹一次管理员授权窗口，同意即可）。
   安装过一次之后，以后每次启动都不再询问。
   如果系统里已经装过 Everything，TT酱 会直接共用它的索引服务，
   不会重复安装、也不会改动原来的 Everything。
3. 双击 Ctrl 唤起窗口。第一次需要等索引建好（右下角状态栏有提示），
   全盘索引一般几十秒到几分钟，之后搜索就是即输即出。

二、日常使用

- 双击 Ctrl：随时唤起 / 收起窗口。窗口被挡住、最小化、收进托盘都能拉回来。
  每次唤起都会清空搜索框，回到图标网格。
- 搜索：直接输入文件名，回车打开第一个结果，单击列表项打开。
  结果显示所有匹配，不设条数上限；状态栏显示总数，滚动时按需加载，
  即使几十万条结果也不会卡住。结果区顶部可点「名称 / 类型 / 修改时间」
  切换排序，再点一次切换升降序；「含路径」开关控制是否按完整路径匹配。
  输入多个词用空格分开，表示文件名里要同时包含这些词，例如 ttjiang exe。
  默认只匹配文件名；点结果区顶部的「含路径」可连目录名一起找。
  结果区顶部的「名称 / 类型 / 修改时间」可切换排序，再点一次切换升降序，
  结果行右侧会显示文件类型与修改时间。
- dx 数字大写：输入 dx 开头加金额，例如 dx1234.56，
  显示「壹仟贰佰叁拾肆元伍角陆分」，点一下即复制。
- 添加快捷方式：右下角「+」方块，或托盘菜单「添加快捷方式…」。
- 设置：窗口右下角齿轮，或托盘菜单「设置…」。
- 退出：托盘图标右键 → 退出。退出时会自动结束内置搜索进程。
- 任务栏只会有 TT酱 一个图标：内置 Everything 在后台提供索引与查询，
  不显示自己的托盘图标、搜索窗口或任务栏按钮。
- 截图与识别：按 Ctrl+1（或托盘菜单「截图」）进入框选，拖动鼠标选择区域，
  选区下方出现四个图标按钮，点按钮或按数字键：
    1 复制图片   2 保存图片   3 识别表格   4 识别文字
  识别结果直接写入剪贴板；表格是 TSV，可直接粘进 Excel / WPS。
  空格按字形间的实际空白还原，英文与中英混排的空格会保留；
  中文之间不插空格（中文不用空格分词）。千分位 1,234.56 会保持逗号。
  Esc 或右键取消，Enter 等于「复制图片」。
  OCR 模型就在程序目录的 ocr 文件夹里，直接用，不往别处拷贝；
  升级版本时替换整个文件夹即可（ocr 目录不变可跳过）。

三、删除

删除整个文件夹即完成卸载。程序、配置、日志、索引全部在这个文件夹里。
从 3.1.0 升级的话，%LOCALAPPDATA%\TT酱\runtime 是旧版释放的模型副本，
新版启动时会自动清掉；想手动删也不影响使用。

两个例外：
1. 如果在托盘菜单里开启过「开机自动启动」，注册表里会留一条启动项，
   可在注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 删除。
2. 如果安装过索引服务且想连服务一起清掉，先在设置里点「卸载索引服务」
   再删文件夹；不卸载也可以直接删，服务会指向空路径，用服务管理移除即可。

四、常见问题

- 搜索提示「索引服务未安装」：打开设置 → 安装索引服务，
  授权一次即可。
- 双击 Ctrl 没反应：托盘菜单里点「重新注册全局热键」。
  以管理员身份运行的程序（如任务管理器）在前台时，普通程序收不到热键，
  这是 Windows 的安全隔离，不是故障。
- Ctrl+1 没反应：可能被其他截图工具（PixPin、Snipaste 等）占用，TT酱 每 3 秒
  重试一次，关掉占用程序后会自动接管；也可以改程序目录下 screenshot.json 的
  hotkey（例如 Ctrl+Alt+1），改完重启 TT酱。
- 托盘图标不见了：Windows 11 会默认把新图标收进任务栏「^」溢出区，拖出来即可；
  另外本版本已修复资源管理器重启后图标消失的问题，无需再手动退出重开。
- 换电脑迁移：把整个文件夹拷走即可，索引会自动重建。
- 识别文字提示「缺少 ocr 文件夹」：TT酱.exe 旁边少了 ocr 目录，
  把压缩包里的 ocr 文件夹放回同一目录即可；截图、存图与搜索不受影响。
- 快捷方式迁移：托盘菜单「导出快捷方式…」存成 json，
  到新机器上「导入快捷方式…」。
