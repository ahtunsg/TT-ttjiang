TT酱 4.3 — 快速启动、全盘搜索与截图 OCR
=====================================

运行环境：Windows 10 1903 及以上 / Windows 11，仅 64 位。
不需要装任何运行时，解压即用：一个约 897 KB 的 TT酱.exe，
加一个约 27 MB 的 ocr 目录（离线 OCR 模型）与约 6 MB 的 everything
目录（搜索引擎）。全程不需要联网。
ocr 与 everything 目录要和 TT酱.exe 放在一起，不要把 exe 单独拷走。

一、快速开始

1. 把整个文件夹放到任意有写入权限的本地目录（桌面、D 盘都可以，
   不要放 Program Files 这类需要管理员权限的目录）。
2. 双击 TT酱.exe。程序默认只驻留托盘，不弹出主窗口；
   双击 Ctrl 或双击托盘图标即可显示窗口。
   开启「开机自动启动」后，开机同样只在托盘待命。
3. 第一次搜索前需要装一次索引服务（弹一次管理员授权窗口，同意即可）。
   安装过一次之后，以后每次启动都不再询问。
   如果系统里已经装过 Everything，TT酱 会直接共用它的索引服务，
   不会重复安装、也不会改动原来的 Everything。
4. 全盘索引一般几十秒到几分钟，建好之后搜索就是即输即出。

二、日常使用

- 双击 Ctrl：随时唤起 / 收起窗口。窗口被挡住、最小化、收进托盘都能拉回来。
  每次唤起都会清空搜索框，回到图标网格。
- 搜索：直接输入文件名，回车打开第一个结果，单击结果项打开。
  搜索框是标准的文本输入框：有光标、能框选、支持 Ctrl+A / Ctrl+C / Ctrl+X / Ctrl+V，
  中文输入法组字跟随光标，多行内容粘贴进来只取第一行。
  结果显示所有匹配，不设条数上限；状态栏显示总数，滚动时按需加载，
  即使几十万条结果也不会卡住。
  输入多个词用空格分开，表示文件名里要同时包含这些词，例如 ttjiang exe。
  默认只匹配文件名；点结果区顶部的「含路径」可连目录名一起找。
  结果区顶部的「名称 / 类型 / 修改时间」可切换排序，再点一次切换升降序，
  结果行右侧会显示文件类型与修改时间。
  结果项右键可以打开、打开所在位置、复制完整路径。
- dx 数字大写：输入 dx 开头加金额，例如 dx1234.56，
  显示「壹仟贰佰叁拾肆元伍角陆分」，点一下即复制。
- 添加 / 修改快捷方式：图标网格里带「+」的格子就是添加按钮，右键已有图标可以编辑或删除。
  格子固定 8 列 × 4 行共 32 格，其中一格是「+ 添加」，摆满就没有空位再添加。
- 放一个网页链接：编辑窗口里只有一个「路径」框，直接填网址就行，
  不需要单独选类型。http://、https:// 开头，或者 www. 开头的，都当作网址；
  file://、盘符路径、共享目录、shell: 这类仍然照旧当文件打开。
  点开网址会直接用系统的默认浏览器打开，走的是浏览器自己的主程序，
  不会弹「你要用哪个应用打开」那一层选择框；这一步万一失败，
  会自动退回让系统自己打开。原来填在「参数」里的内容会一并传给浏览器。
  网址的图标显示域名首字母（www.baidu.com 显示 B、www.zhihu.com 显示 Z，
  取的是域名而不是 www. 的 W；名字里有中文时取名字第一个字，
  例如名字叫「知乎」就显示「知」）。
  想要真图标，在编辑窗口的「图标」里选一张自己存的 png / ico，它会盖过默认图标。
  说明：软件不会去读浏览器的图标缓存，也不会联网抓 favicon。浏览器的网站图标
  只存在浏览器自己的数据库里，那个库通常正被浏览器占用着，而本软件全程不联网，
  所以网址图标只能靠首字母或你自己指定。已存好的图标位置记在
  shortcuts.json 的 icon 字段里。
  窗口大小按屏幕比例自动定、不能拖动改变，格子数量在任何分辨率下都是 8 × 4；
  弹出位置比屏幕正中偏下一点（屏幕高度的 10%），不会被屏幕上沿压住。
- 调整图标位置：按住图标拖到想放的格子，松手即生效。
  拖到空格子会占住那一格、原位置空出来；拖到已有图标的格子会两者互换。
  位置会记在 shortcuts.json 里，下次打开还在。
- 设置：窗口右下角齿轮。
- 操作提示默认关闭：不弹「文字已复制到剪贴板（N 行）」「图片已保存」
  这类浮层，首次启动时托盘区的气泡提示也不弹。复制、保存、识别的结果
  照常生效，只是没有视觉反馈；错误提示（识别失败、缺少 ocr 文件夹等）
  也会一并隐藏。需要恢复时，把程序目录下 config.json 里的
  "show_toast": false 改成 true，重启 TT酱 即可。
- 退出：右键托盘图标 → 退出。退出时会自动结束内置搜索进程。
- 任务栏只会有 TT酱 一个图标：内置 Everything 在后台提供索引与查询，
  不显示自己的托盘图标、搜索窗口或任务栏按钮。
- 关于：托盘菜单「关于 TT酱…」，里面有版本号与项目地址。
- 截图与识别：按 Ctrl+1（或托盘菜单「截图」）进入框选，拖动鼠标选择区域，
  选区下方出现四个图标按钮，点按钮或按数字键：
    1 复制图片   2 保存图片   3 识别表格   4 识别文字
  保存图片会弹出另存为对话框，可以自己选目录，格式固定 PNG；
  下次再保存会默认停在上次选的目录。
  识别结果直接写入剪贴板；表格是 TSV，可直接粘进 Excel / WPS。
  Esc 或右键取消，框选前、框选后都能按；Enter 等于「复制图片」。
  OCR 模型就在程序目录的 ocr 文件夹里，直接用，不往别处拷贝，也不联网。
  4.3 用混合模型：检测用 PP-OCRv6 small，识别用 PP-OCRv6 tiny。
  窄列、密集小表格的检出保持 4.2 的水平（六列表格 36/36），
  识别耗时大约只有 4.2 的一半（17 张回归图均值 537ms → 270ms，
  中位 448ms → 217ms）。代价是少数字形相近的字比 4.2 容易认错，
  生僻字覆盖也少一些；全屏满文字的截图仍需 0.5 秒左右。
  从 4.1 或 4.2 升级时不能只覆盖 TT酱.exe，必须用本包 ocr 目录里的
  det.onnx、rec.onnx、keys.txt 三个文件整体替换旧文件；
  混着放会提示「模型与字典不是 4.3 的那一套」并拒绝识别。

三、删除

删除整个文件夹即完成卸载。程序、配置、日志、索引全部在这个文件夹里。

两个例外：
1. 如果在托盘菜单里开启过「开机自动启动」，注册表里会留一条启动项，
   可在注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 删除。
2. 如果安装过索引服务且想连服务一起清掉，可用系统的服务管理移除。

四、常见问题

- 搜索提示索引服务未就绪：打开设置（右下角齿轮），点「启动内置索引服务」，
  授权一次即可。
- 双击 Ctrl 没反应：托盘菜单里点「重新注册全局热键」。
  以管理员身份运行的程序（如任务管理器）在前台时，普通程序收不到热键，
  这是 Windows 的安全隔离，不是故障。
- Ctrl+1 没反应：可能被其他截图工具（PixPin、Snipaste 等）占用，TT酱 每 3 秒
  重试一次，关掉占用程序后会自动接管；也可以改程序目录下 config.json 的
  hotkey（例如 Ctrl+Alt+1），改完重启 TT酱。
- 托盘图标不见了：Windows 11 会默认把新图标收进任务栏「^」溢出区，拖出来即可。
- 换电脑迁移：把整个文件夹拷走即可，索引会自动重建。
- 识别文字提示「缺少 ocr 文件夹」：TT酱.exe 旁边少了 ocr 目录，
  把压缩包里的 ocr 文件夹放回同一目录即可；截图、存图与搜索不受影响。
- 识别文字提示「模型与字典不是 4.3 的那一套」：ocr 目录里混了 4.2 的
  rec.onnx / keys.txt（或 4.1 的旧文件），用 4.3 包里的三个文件整体替换即可。
- 快捷方式迁移：托盘菜单「导出快捷方式…」存成 json，
  到新机器上「导入快捷方式…」。
